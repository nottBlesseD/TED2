## Breve Descrição do Projeto
O **CentralRecursivaRobusta** é um sistema modularizado em Python desenvolvido para processar operações matemáticas utilizando funções puramente **recursivas**. O programa é capaz de calcular o Máximo Divisor Comum (MDC) de dois números inteiros positivos e a Soma dos Dígitos de um número inteiro não negativo. Além disso, conta com um sistema robusto de validação de dados e tratamento de exceções personalizadas.
